# AI 협업 경계

이 프로젝트는 AI 코딩 도구를 구현 보조로 사용한 개인 프로젝트입니다. 사람 팀원이 없었다는 사실과 AI를 사용했다는 사실을 분리해 설명합니다.

## 사람이 책임진 범위

- 어떤 사용자 문제를 다룰지 결정
- 두 기업과 보고서, 지표의 지원 범위 선택
- SQL 계산과 LLM 설명의 권한 분리
- 근거 부족과 시스템 장애의 실패 의미 정의
- 대표값 선택 오류의 원인 규명
- 수정 방향과 수용 기준 결정
- 테스트 결과와 공개 범위 확인

## AI가 도운 범위

- 코드와 테스트 초안 작성
- 반복적인 구현 작업 보조
- 문서 구조와 검토 질문 제안
- 놓칠 수 있는 경계 조건의 후보 제시

AI가 생성한 코드를 그대로 정답으로 간주하지 않았습니다. 원천 데이터, 데이터 계약, 회귀 테스트, 실행 결과를 기준으로 채택 여부를 판단했어요.

## 공개 증거의 한계

프로젝트별 prompt 원문, AI 제안을 거절한 구체적 사례, 수정 전후의 완전한 대화 로그는 정본으로 보존되어 있지 않습니다. 따라서 다음과 같은 주장은 하지 않습니다.

- 특정 AI 제안을 거절해 품질을 높였다는 구체적 사례
- AI가 설계한 시스템을 사람이 단순 실행했다는 주장
- AI 사용만으로 개발 생산성이 몇 배 개선됐다는 수치
- 사용한 모델이 결과 품질을 보장했다는 표현

면접에서는 저장소 코드와 테스트로 설명 가능한 판단부터 답합니다. 추가 증거가 없는 AI 대화는 기억에 의존해 재구성하지 않아요.
